# Tuba Khan Portfolio – Hero Section

This project is a professional portfolio site for **Tuba Khan (Strategic Content Specialist & Web Copywriter)**, designed to closely replicate the dark, modern layout and typography of the provided inspiration.

Currently, the implementation includes:

- A full hero section with:
  - Deep navy / black background
  - Large, outlined background `HELLO` text
  - Central profile card using Tuba's hero photo
  - Headline, sub-headline, and introduction copy
  - Primary **VIEW MY WORK** and secondary **DOWNLOAD CV** buttons

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start a local dev server:

   ```bash
   npm start
   ```

3. Open the site in your browser (if it doesn't open automatically) at:

   ```bash
   http://localhost:5500
   ```

> **Note:** The **DOWNLOAD CV** button is currently wired to a local file path `d:/tuba-khan-cv.pdf.pdf`. For deployment, copy the CV into the project (for example, `public/tuba-khan-cv.pdf`) and update the link in `index.html` accordingly.
